Nota

Your day, one note at a time.

A desktop note app built around a single idea: one dated workplan per day. When tomorrow starts, the things you didn't finish come with you and the things you did stay behind. Everything is a plain markdown file in a directory you own.

What it does

Small on purpose. These are the things a working day actually needs.

Rollover that remembers

Unfinished items move to the new day keeping their id, original creation time, labels, logged time, notes and nesting. Finished ones stay on the day you finished them.

No broken chains

Monday carries from Friday. The rule is "the most recent workplan", never "yesterday", so weekends, leave and holidays don't lose your list.

Hours per day

Every workplan shows the time worked — 2026-09-02 - 09:00 — sitting at 00:00 on a weekend, leave day or holiday. One figure per day, set by you.

When did I add this?

Every item records the moment you typed it, and keeps it across every rollover. An item nagging you since the 1st still says so on the 5th.

Labels, optional

Type #label anywhere in an item. Search by it later, or ignore the feature entirely — nothing requires one.

Code and JSON

Fenced blocks with real syntax highlighting, under an item or anywhere on the page. Paste a stack trace and it still reads like one.

Repeating items

Check the calendar, log the bill. Daily, weekdays or a given weekday, from one hand-editable file. Delete one for today and it stays gone for today.

Export and restore

One zip of the whole vault, and back again. Complete by construction, because the markdown is the data.

Paste a picture

Paste a screenshot into a page's notes or an item's notes. It lands in attachments/ in your vault and is linked as ordinary markdown, so it opens in any editor and travels in your backups.

Updates, if you want them

Nota can check GitHub for a newer version and install it in one click, verifying the published checksum first. It asks before it ever uses the network, and no means never — this is the only request Nota makes.

Nested folders

The sidebar tree is the directory tree: folders hold pages, and a page holds items, notes or both. Make, rename and delete them there. Nothing is hidden in a database you can't read.

Headings between items

Type ## Must on an empty row and everything after it is grouped. A heading rolls over with its open items and disappears once the group is done.

One click, one key

Hover any item for done, delete and move-to-today. Ctrl+Enter, Ctrl+Backspace and Ctrl+Shift+M do the same from the keyboard.

Your fonts

Inter, Manrope or IBM Plex Sans for the interface; Lora or Source Serif 4 for notes; JetBrains Mono for code. Bundled with the app, three sizes, nothing fetched.

Looks like your desktop

Light, dark, or follow the system. Opens maximised the first time, then remembers the size and position you leave it at.

Your notes stay yours

The markdown files are the source of truth. The app keeps a SQLite index for search, but it's a cache — delete it and it rebuilds. If Nota disappeared tomorrow, your notes would still open in any editor.

Labels stay visible where you'd write them. Only ids and timestamps hide in a comment markdown doesn't render. The filename stays the date — the hours live in the frontmatter, so setting them never renames a file.

Install

No root or administrator rights. Both scripts verify the download against the release's published SHA-256 before installing anything.

Linux

curl -fsSL https://raw.githubusercontent.com/\
vishnu-kyatannawar/nota/main/install.sh | sh

Installs to ~/.local/bin with a desktop entry. Needs GTK4 and WebKitGTK 6 — the script checks first and prints the right package name for your distribution.

Windows

irm https://raw.githubusercontent.com/\
vishnu-kyatannawar/nota/main/install.ps1 | iex

Installs to %LOCALAPPDATA%\Programs\Nota with a Start menu shortcut. Needs WebView2, which ships with Windows 10 21H2 and later.

Prefer to build it yourself? git clone, then wails3 build. The README has the full list.
